# 示例词书

这两个 JSON 是「新建词书」弹窗需要的格式，可以直接下载下来导入：

| 文件 | 词数 | 说明 |
|---|---|---|
| `cet4.json` | 5833 | 大学英语四级常用词 |
| `cet6.json` | 8029 | 大学英语六级常用词 |

## 格式

```json
{
 "data": [
  {
   "word": "abandon",
   "translation": "n. 狂热；放任\nvt. 遗弃；放弃"
  },
  {
   "word": "ability",
   "translation": "n. 能力，才能；本领"
  }
 ]
}
```

- 最外层是 `{"data": [...]}`（直接给数组也可以）
- 每个词条必须有 `word`；`translation` 可省略，省略时导入后显示为空释义
- `translation` 里的 `\n` 表示换行，导入后会原样保留
- 同一个 `word` 只保留第一条；大小写不同视为不同的词（`China` 与 `china` 各算一条）

## 怎么导入

1. 打开程序 → **仪表盘**
2. 点 **＋ 新建词书（粘贴 JSON）**
3. 填词书名（例如 `cet4`）
4. 点 **从文件读取…** 选本文件夹里的 JSON（文件较大时用这个，比复制粘贴可靠）
5. 点 **确认导入**

导入成功后，回到首页或仪表盘把当前词书切换过去即可。
